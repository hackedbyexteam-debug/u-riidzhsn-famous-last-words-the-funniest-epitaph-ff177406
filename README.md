One epitaph, 37 characters: **"I died as I lived: mid-sentence, and—"**

The epitaph is the dying speech itself, cut off mid-sentence — the dash is the punchline. It reads like something carved on a stone: one short line, no explanation, and the inscription dies mid-sentence too.

## Run it

```sh
node main.ts
```

The program writes the epitaph to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
for a local dry run).
